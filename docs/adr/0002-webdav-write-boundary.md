# 先加入目标库，再决定能否写回网盘

恢复 `.vaultpack` 是取回凭证，不是认领原同步库。连接已有远端库，先以其主密码或恢复码验证，再打开备份、预览并确认迁入；保留远端库身份及恢复码。无法验证远端时，两份数据保持独立。

锁库后停止发起新的同步请求，不因有待传数据而解封网盘密码。本地密文队列保留，解锁后先核对已提交进度再续传；锁库不是撤销已送达网盘的请求。

不能证明 WebDAV 服务能拒绝基于旧版本的条件写时，只支持读取恢复，不建库、不发布新版本、不删除历史。能验证某个快照确实属于同一库，并不能证明可以安全覆盖网盘上另一台设备刚写入的内容。

旧客户端找不到可验证的共同版本，或无法无损保留不认识的字段时，停止自动写回并保留本地编辑。升级或显式合并后才续传；不能仅因旧端离线太久，就舍弃它的改动或用它覆盖新版库。

恢复历史内容不恢复已经用掉的计数。对同一枚 HOTP 或启用递增签名计数的 Passkey，保留各可信记录中的最高计数；无法确认时暂停该凭证，先重新同步或在网站重新登记。默认 `signCount = 0` 的 Passkey 不涉及计数回退。
