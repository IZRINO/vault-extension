Vault 0.2.0 为新建的 WebDAV 密码库加入加密整包同步。空闲时只检查版本记录，有新修改时才传输整包。适用于 Microsoft Edge 和 Helium。

### 同步与恢复

- 两台设备离线修改不同条目后，重新联网即可合并。修改同一字段，或新增同账号但密码不同的登录时，可以查看各自的来源设备，选择一方或保留双份。其余条目继续同步。
- 新设备可以用目标库的主密码或恢复码加入，同步 Passkey、验证器和安全备注。网站自动填充开关和关联域名可预览、选用或跳过。
- 可预览最近五个已合并版本，并将选定版本恢复为新版本。从旧 `.vaultpack` 显式恢复已永久删除的条目后，其他设备也能按原 ID 读回。
- 设置页会提示尚待合并的版本和上次失败的检查。认证失败或网盘限流会暂停该端点的请求。已发布记录的完整性校验失败时，连接转为只读，本机修改保留。

### 安装与升级

1. 下载附件 `Vault-0.2.0-chrome-mv3.zip`。可运行 `Get-FileHash .\Vault-0.2.0-chrome-mv3.zip -Algorithm SHA256`，与 `SHA256SUMS.txt` 核对。
2. 首次安装时，将 ZIP 解压到固定目录，在 `edge://extensions` 或 Helium 的 `chrome://extensions` 开启开发者模式，选择「加载解压缩的扩展」，选中含 `manifest.json` 的目录。
3. 从 v0.1.0 升级时，先导出加密 `.vaultpack` 备份，保留已安装的扩展。将新版解压到原安装目录，再点击「重新加载」。同一同步库的设备请一起升级。
4. 已有 WebDAV 增量库继续使用原协议。试用整包同步时，请选择新的专用目录，在目标库预览并确认要迁入的凭证。

### 正式包验证

同一份发布 ZIP 在 Edge `158.0.4370.45` 和 Helium `158.0.8127.88` 通过整包同步、冲突裁决和恢复测试。空闲检查只传版本元数据，整包收发均为 0 B。Edge 发布后锁库，全新 Helium 配置成功完成了 Passkey 新挑战签名、独立 TOTP 校验和多行安全备注读回。Rust 101 项、Vitest 308 项和 TypeScript 类型检查全部通过。

安装 ZIP 的 SHA-256 为 `7b6f236af3be53ba04cc82b1fae0008d80c51fd814db97b6e6971458cad74d92`。

### 网盘兼容性

Koofr 最近一次实测完整读回了 JSON 封装的加密包，但同名条件创建覆盖了已有探针。Vault 因此会在发布远端库之前停止写入。坚果云仍待新版实测。自定义 WebDAV 须通过所选目录的整包读回、同名排他创建和版本枚举验证，才能启用写入。[网盘实测记录](https://github.com/IZRINO/vault-extension/blob/v0.2.0/docs/agents/whole-pack-webdav.md) · [工单 #52](https://github.com/IZRINO/vault-extension/issues/52)
