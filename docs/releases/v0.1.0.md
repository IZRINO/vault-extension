Vault 首个 GitHub 正式版，适用于 Microsoft Edge 和 Helium。密码库加密保存在本机，无需注册账号。

### 下载与安装

1. 下载附件 `Vault-0.1.0-chrome-mv3.zip`，解压到准备长期保留的目录。`Source code` 是源码，不是安装包。
2. 打开 Edge 的 `edge://extensions` 或 Helium 的 `chrome://extensions`，开启「开发者模式」，选择「加载解压缩的扩展」，选中含 `manifest.json` 的目录。
3. 要校验下载文件，可在 PowerShell 运行 `Get-FileHash .\Vault-0.1.0-chrome-mv3.zip -Algorithm SHA256`，与附件 `SHA256SUMS.txt` 对照。

### 本版功能

- 保存、更新和填入网站登录信息，支持 Passkey 和 TOTP、HOTP、Steam 动态码。自动识别失败时，可以在当前网站手动标记登录框。
- 迁入浏览器 CSV、Bitwarden、KeePass 和 Ente Auth 等格式。先预览再确认；导出 Bitwarden 时会区分可用、未导出和无法核实的 Passkey。
- 支持 `.vaultpack` 加密备份和可选 WebDAV 同步。并发编辑有冲突时，可以载入新版本并保留草稿，确认后再写入。

### 升级与已知限制

- **先导出 `.vaultpack` 再升级，不要卸载原扩展。** 解压到原安装目录后，在扩展管理页点击「重新加载」。恢复码可以重设主密码，但不能代替凭证备份。
- 同一个 WebDAV 库的设备建议一起升级。旧客户端不参与本版的容量登记；新旧混用时不能保证并发写入不会超出读取上限。
- 登录框标记目前只在本机加密保存，不随 `.vaultpack` 或 WebDAV 迁移。
- 本版经过 Edge、Helium 的自动化验证，不代表所有真实网站、网盘、实体 Windows Hello / USB 密钥及第三方应用均已验收。独立 WASM 会话恢复的 5 毫秒性能目标也未作为达标结论。此版本由 GitHub 分发，未上架扩展商店。
