## 方法与复现

- 五个实验分别是：在开库脚本上设置高优先级并减少 Popup 的推测性脚本预加载；让列表按钮复用 Lucide 的 SVG 笔画；后台将 WASM 的脱敏摘要字符串交给弹窗解析，旧调用仍可取数组；受信开库消息到达后并行打开数据库连接，记录读取仍等待访问限制生效；在 Zstd 解压中合并三个连续的状态转移位读取。最后一项主 WASM 为 250,597 B（原版 250,433 B），仍小于 256,000 B。
- 生产目录逐臂复制到同一安装路径，测量前后按文件树哈希验包。每批使用全新临时配置，每个样本先确认 Worker 停止，再触发原生工具栏；DOM 提交后检查合成条目可见、启用并可命中。每批校验 32 行初始分页、续页、屏外聚焦、全库搜索及 Enter 打开。未预热，未省略功能，未使用单次状态请求往返或骨架屏充当可用首屏。
- 初筛每臂两批，每批每浏览器 5 次。第一轮顺序为 ④、原版、⑤、①、③、②，先 Edge 后 Helium；第二轮候选与浏览器顺序都反转。复测采用原版、第一名、第一名、原版，同样调换浏览器顺序，独立于初筛。每个表格单元合并两批的十个样本再求中位数，不取两个批次中位数的平均。不是硬件隔离测量，系统调度、浏览器状态等仍可造成波动。
- 仓库脚本：`node scripts/test-wakeup.cjs edge helium`，设置 `VAULT_EXTENSION_PATH`、`VAULT_WAKE_ITEMS=1000`、`VAULT_WAKE_SAMPLES=5`、每批唯一的 `VAULT_WAKE_REPORT_LABEL`，关闭 trace。脚本在保存数据后因未达门槛返回 1；采样中断或缺失报告不会计入结果。
- 复测中有一批在测量前等 Helium 内置过滤器就绪时超时，未产生样本；原设置下换新配置重跑该批。未关闭过滤器或排除已完成的样本。
