# 加密整包 WebDAV 验证（#52）

[工单 #52](https://github.com/IZRINO/vault-extension/issues/52) · [ADR-0002](../adr/0002-webdav-write-boundary.md)

验收时把一个新目录选作测试库的同步目录，不覆盖已连接的增量库，也不需要手建另一个探针目录。搬迁凭证时先保留原库的 `.vaultpack`，用目标库的主密码或恢复码验证并加入目标，再预览、确认导入。不要用真实凭证做回归。

## 回环复测

1. 用 `pnpm run build` 构建。可设置 `VAULT_EXTENSION_PATH` 指向解压后的同一个扩展构建目录。
2. 用 `pnpm run test:pack-sync` 启动 Edge、Helium 的独立测试配置。脚本使用本机 WebDAV 故障服务和合成库，输出 `test-results/pack-sync-loopback.json`。分别记录版本查询和整包传输字节数。
3. 旧格式的包大小与增量压实仍用旧版构建作为基线。`test:passkeys`、`scripts/test-sync-lifecycle.cjs` 中依赖 `head.bin`、`wal/`、增量压实的步骤，应把 `VAULT_EXTENSION_PATH` 指向 #52 之前的构建。

同一解压构建 `e52341219f7d7720bfb564191345d2bea0fd8bb4c1d71608411493ed61dac97c` 在 Edge `158.0.4370.45` 和 Helium `158.0.8127.88` 通过二进制整包回环。下表统计同步目录内的请求和响应正文。单个探针文件的传输另列，`PROPFIND` 计入元数据。

| 操作 | 元数据上行 / 下行 | 整包上行 / 下行 | 探针文件上行 / 下行 |
| --- | ---: | ---: | ---: |
| 建库 | 2,715 / 8,376 B | 1,950 / 1,950 B | 1,864 / 4,668 B |
| 空闲检查 | 145 / 234 B | 0 / 0 B | 0 / 0 B |
| 加入 | 725 / 6,402 B | 0 / 1,950 B | 0 / 0 B |

回归覆盖：同目录验证、包暂存后断网、发布回执丢失、建库途中完全关闭并重开浏览器、另一端先建库后可加入、两个并发分支、联网期间继续本地编辑、凭证与 HOTP 可用、网站规则选用与跳过、关联域名裁决、五个历史版本、锁库续传、空库与批量删除保护、防回滚、401/429 熔断，以及远端找不到夹具秘密明文。真实网盘不以此结果代签。

`test:pack-sync` 也从扩展的正式入口验证非空库迁入。目标库先保留一项待裁决修改，源库再导入一条无关凭证和一条同账号异密码的凭证。另一端应能立即读到无关凭证、裁决两项分歧，并从密码历史查到落选密码的来源设备。永久删除已同步的凭证后，从旧 `.vaultpack` 显式恢复该条目，另一端应能以原 ID 读回。跨设备试用前请将各端更新至同一新版，旧版无法处理跨 ID 的重复账号裁决或带设备来源的待合并草稿。

2026-11-27，构建 `5682ceffb4d3c8c98ac1ce17330bbeded2eceff01f1e66d18120c00484a18dd3` 的安装 ZIP 解压后，在上述 Edge、Helium 通过完整回环及迁入、裁决、恢复回归。发现并发分支后，设置页保留待办直至合并。自动检查遇到历史记录缺失时，重新打开设置可见失败提示，下一次成功检查后清除。空闲检查的元数据上行 / 下行仍为 145 / 234 B，整包为 0 / 0 B。另一轮用同一构建在 Edge 发布后锁库，由全新 Helium 配置读取多行安全备注、校验独立 TOTP，并用 Edge 登记的公钥验证了 Helium 对新挑战的 ES256 签名。

## 真网盘签收

2026-11-27，用早期构建 `72aaa4394b479c86c8f494009c9bf030f8e1e89c3cd8fc327004ceba48d0f4db` 在独立浏览器配置发起真实服务验收。当时还要求单独建探针目录，两家都停在该目录的写入验证，未到最终整包发布阶段。

| 服务与浏览器 | 写入验证结果 | 最终整包往返、并发与中断恢复 |
| --- | --- | --- |
| Koofr / Edge `158.0.4370.45` | 测试文件声明 32 B，扩展实际收到 0 B。字节数来自页面；未获得本轮探针完整请求链，也未复验排他创建。 | 未进入建库步骤，不开放写入。 |
| 坚果云 / Helium `158.0.8127.88` | 页面提示「测试文件内容不符或缺少强版本标签」。未能区分正文比对失败、缺少 `ETag` 或标签不是强 `ETag`。 | 未进入建库步骤，不开放写入。 |

两家目标新目录的 `PROPFIND 404` 与目录尚不存在一致，不是上述失败的原因。只采集脱敏的浏览器状态、请求分类和页面错误，没有采集认证头或正文。专用测试目录可能留下无法安全清理的探针；未手动删除网盘文件。

### Koofr 同目录复测（2026-11-27）

| 构建 / Edge `158.0.4370.45` | 加密整包往返 | 写入验证 |
| --- | --- | --- |
| `c148b861577d`，二进制 | PUT `201`。GET `200`，强 ETag，声明 1,694 B，Vault 收到 0 B。 | 停在整包读回。 |
| `e52341219f7d`，JSON | PUT `201`。GET `200`，强 ETag，2,277 B 的 JSON 完整读回，解码后的密文长度和 SHA-256 通过。 | 文本探针的两次同名 PUT 均带 `If-None-Match: *`，均返回 `201`，随后读回长度从 730 B 变为 60 B。 |

JSON 这次通过了整包完整性检查，但 Koofr 接受了同名覆盖，Vault 停止发布。该探针已条件删除并复查 `404`。本轮没有发送 `pack-root.txt` 的 PUT，测试目录内仍有暂存的加密包。脱敏记录位于本机 `test-results/pack-live-c148/`。坚果云暂缓复测。

验收使用同一新版构建、专用测试账号和新同步目录。建库成功后，用另一端通过恢复码加入，验证密文大小、网站规则选用、空闲检查和多端独立发布。故障注入只在本机回环进行。

目前只展示最近五个已合并版本。远端历史和可能仍被离线设备引用的包不自动删除；目录接近安全读取上限时停止发布并保留本机编辑。导出 `.vaultpack`、使用新空目录迁移可继续试用。
