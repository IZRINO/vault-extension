# 领域文档约定

这个仓库按一个产品维护术语和架构决策；不按 `apps/` 或 `crates/` 拆分。

- **术语**：开始相关工作前，若根目录已有 `GLOSSARY.md`，先查其中的定义。工单、规格和测试使用同一个名称；遇到尚未定义的概念，先澄清含义，再记录约定。
- **架构决策**：若已有 `docs/adr/`，先读与当前改动有关的决策记录。提案与已有决策冲突时，指出记录编号和重新讨论的理由，不默默覆盖。
- **按需创建**：两处路径都是约定，不是前置条件。尚无术语表或决策记录时直接继续；有了第一个确定的术语或决策，再创建相应文件。

技术选型以[架构与选型文档](../../密码管理器浏览器插件-技术架构与选型文档.md)为准，交付范围和验收条件以[分期开发与验证计划](../../分期开发与验证计划.md)为准。术语表和决策记录不替代这两份文档。
