## 最小接入与验收

- 在[验证码导入器](../../crates/vault-importers/src/authenticators.rs)按用户显式选的 `freeotp-plus` / `winauth` 分流。先校验字节、条数、单行和种子长度；FreeOTP+ JSON 两个数组都限量，文本严格 UTF-8、允许 BOM 及空行，WinAuth 可忽略 `#` 注释。文件不凭 `.json` / `.txt` 或发行方猜来源；看到不支持的 ZIP/PGP/XML 给出对应重新导出指引。用 `Zeroizing` 缓冲和 `vault_otp::encode_base32`，来源特有的计数、类型、账号转义、默认值先验证，再复用 `Batch`、`Mapping` 和 `vault_otp::parse`。保留完整账号（包括 `:`）；无发行方时不要让通用解析器把账号首段误当发行方。`Mapping` 会给空 HOTP 计数默认 `0`、会把 Steam 步长/位数固定成 30/5，所以这些值不得在来源预校验缺失或不符时落入通用默认。源额外字段不用会话、URL、远程资源或 WebView 解释。
- 保留[验证码备份预览与确认](../../apps/extension/src/vault-controller.ts#L940-L983)的 4 MiB、5,000 条上限及预览戳、真正导入时的重新验证；未知与损坏区分计数，预览及日志不返回验证码种子或 WinAuth 附加敏感数据。[现有去重](../../apps/extension/src/migration.ts#L39-L65)忽略 HOTP 计数，不用旧备份覆盖已存在记录。保持 [ADR-0001](../adr/0001-secret-use-and-export.md) 的动态码与可复用秘密分离。
- **FreeOTP+ 原生样本**：用官方 APK 在独立 Android 测试配置中导入合成 URI，再导出 JSON 和文本；也可复用上游 Android instrumentation 测试，调用同一 writer。测试含有/无发行方、冒号账号、重复 ID、分类、负 Java 字节、非默认算法与周期、Steam。HOTP 用正计数，导出后只在测试副本生成一枚下一码与 Vault 对照。官方用例确实包含合成 JSON/TXT 往返，但本轮未运行 Android 应用，不能把仓库测试文本叫作原生导出。[官方 APK](https://github.com/helloworld1/FreeOTPPlus/releases/tag/RELEASE-3.5) · [JSON writer 测试](https://github.com/helloworld1/FreeOTPPlus/blob/c4adb2c904fc2ed5d389f359abe369fb09f4eadb/app/src/androidTest/java/org/fedorahosted/freeotp/uitest/ImportExportTest.kt#L66-L103) · [文本 writer 测试](https://github.com/helloworld1/FreeOTPPlus/blob/c4adb2c904fc2ed5d389f359abe369fb09f4eadb/app/src/androidTest/java/org/fedorahosted/freeotp/uitest/ImportExportTest.kt#L170-L198)

**本轮独立核算**：上游 FreeOTP+ 两条公开合成 `byte[]` 转出的 Base32 与上游断言相同。[RFC 4226 附录 D](https://www.rfc-editor.org/rfc/rfc4226#appendix-D) 的合成种子做偏移对照：FreeOTP+ JSON `counter=7` 与 FreeOTP+ TXT `counter=8` 映射为下一计数 `7`，得 `162583`；WinAuth TXT `counter=7` 映射为下一计数 `8`，得 `399871`。另用 [NuGet 官方包中的 `lib/20` DLL](https://api.nuget.org/v3-flatcontainer/sharpziplib/0.86.0/sharpziplib.0.86.0.nupkg)（装配版本 `0.86.0.518`，DLL SHA-256 `40b3d590f95191f3e33e5d00e534fa40f823d9b1bb2a9afe05f139c4e0a3af8d`）驱动相同 ZIP writer，产物标志 `0x0009`、方法 `8`，Python 传统 ZIP 解密读回合成文本且拒绝错密。这是字节、计数与依赖行为的独立核验，不是 Vault 导入测试，也不代签源应用 GUI 往返。
